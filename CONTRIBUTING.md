# Contributing to Termux Droid

This project is maintained by RuusianP.

## How to Contribute

1. Fork the repository on GitHub: https://github.com/RuusianP/TermuxDroid
2. Create a feature branch from `main`
3. Make your changes and test them thoroughly
4. Submit a pull request with a clear description of the changes

## Guidelines

- All scripts must be compatible with Android/Termux environments
- Maintain backward compatibility with existing Proot and Chroot modes
- Test changes on both rooted and non-rooted devices where applicable
- Do not reference or depend on external repositories other than this one
- Follow the existing code style and patterns in the project

## Reporting Issues

Please open an issue on GitHub with:
- A clear description of the problem
- Device model and Android version
- Steps to reproduce
- Expected vs actual behavior
