# Code of Conduct

## Our Standards

This project is maintained by RuusianP. Contributors are expected to uphold the following values:

- Respect and inclusivity toward all users regardless of device, ROM, or skill level
- Constructive feedback in pull requests and issues
- Helpful documentation that benefits the community
- No spam, harassment, or offensive content

## Enforcement

Violations of this code of conduct will be reviewed by the project maintainer (RuusianP) and may result in removal of privileges or banning from the project.
