# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Termux Droid, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

Instead, contact the maintainer directly or use a private reporting channel.

## Supported Versions

The latest release on the main branch is the actively supported version.

## Scope

This security policy covers:
- The setup scripts and configuration files in this repository
- The Raspberry Pi bridge launcher script
- Any modifications or forks of this project

## Removals

Patches will be applied promptly to confirmed vulnerabilities and released with the next version update.
